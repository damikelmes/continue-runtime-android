# Continue Runtime Android

Distribuição oficial da base compilada dos jogos exportados pela Continue. Este repositório contém somente binários, metadados e avisos de licença. O código-fonte do motor e os projetos dos usuários não ficam aqui.

Versão 0.1.0: Android 5.0/API 21 ou superior, GPU OpenGL ES 3.0, ARM64 e ARMv7. Compatibilidade real depende do aparelho.

Baixe os arquivos da Release v0.1.0. Cada versão tem um AAR e SHA-256 fixos. O editor usa a versão/hash exatos; não depende de latest e não recompila C++ por jogo. Uma atualização do runtime só é publicada sob pedido.

O runtime pode acompanhar os jogos nas condições de LICENSE-Continue.txt. Dependências conservam suas próprias licenças; veja THIRD-PARTY-NOTICES.txt.
